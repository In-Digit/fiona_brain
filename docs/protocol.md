📋 Спецификация UDP-протокола Fiona-Net (v1.0)

1. Общие принципы

    Транспорт: UDP. Порт 5000 (для Broadcast-стрима и приема данных от модулей).

    Порядок байт: Little-Endian (стандарт для ARM/ESP).

    Типы данных: uint8_t (1 байт), int8_t (1 байт, со знаком), uint16_t (2 байта), uint32_t (4 байта).

2. Структура любого пакета (Header)
Каждый пакет начинается с 5-байтового заголовка:
Смещение	Размер	Имя	Описание
0	1	MAGIC	Тип пакета: 0xAA (Стрим от ноута), 0xDD (Данные от модуля), 0xBB (Команда)
1	1	SRC_ID	ID отправителя: 0 - HUD, 1 - Ноут, 2 - Подкапотня, 3 - Салон...
2	1	DST_ID	ID получателя: 0xFF - Broadcast (всем), или конкретный ID
3	1	SEQ	Счетчик пакетов (0-255). Нужен для отсева дублей.
4	1	MASK_LEN	Длина маски в байтах. 8 для стрима (64 бита), 2 для модулей (16 бит)
5	N	MASK	Битовая маска (N = MASK_LEN)
5+N	...	PAYLOAD	Данные, упакованные в соответствии с маской
Конец	1	CRC8	Контрольная сумма всех предыдущих байт (полином 0x8C)

3. Пакет 0xAA (Стрим от Ноута)

    SRC_ID = 1, DST_ID = 0xFF (Broadcast).

    MASK_LEN = 8 (64 бита, задел на будущее).

    Карта битов (Payload):

        Бит 0: RPM (uint16_t, 2 байта)

        Бит 1: Speed (uint8_t, 1 байт, км/ч)

        Бит 2: Coolant (int8_t, 1 байт, значение + 40)

        Бит 3: Voltage (uint8_t, 1 байт, значение * 10, т.е. 142 = 14.2В)

        Бит 4: Fuel (uint8_t, 1 байт, литры)

        Бит 5: Range (uint16_t, 2 байта, км)

        Бит 6: Odo (uint32_t, 4 байта, км)

        Бит 7: Флаги (1 байт): бит 0 - двигатель, бит 1 - калибровка, бит 2 - заморозка, бит 3 - нужна калибровка топлива, бит 4 - нужна калибровка одометра.

        Бит 8: Режим движения (uint8_t: 1-город, 2-трасса, 3-спорт)

        Бит 9: Манера езды (uint8_t: 1-спокойно, 2-агрессивно)

        Бит 10: MAF (uint16_t, 2 байта, значение * 100)

        Бит 11: Время (uint32_t, 4 байта, Unix time)

4. Пакет 0xDD (Данные от модуля к Ноуту)

    SRC_ID = [ID модуля], DST_ID = 1 (Ноут).

    MASK_LEN = 2 (16 бит достаточно для любого модуля).

    Пример для Подкапотни (ID 2):

        Бит 0: Температура радиатора (int8_t, +40)

        Бит 1: Уличная температура (int8_t, +40)

        Бит 2: PWM вентилятора 1 (uint8_t)

        Бит 3: PWM вентилятора 2 (uint8_t)

    Пример для Салона (ID 3):

        Бит 0: Температура в салоне (int8_t, +40)

        Бит 1: Влажность (uint8_t, %)

        Бит 2: Байт концевиков (биты: 0-4 двери, 5-багажник, 6-капот, 7-бензобак)

5. Пакет 0xBB (Команда от Ноута к Модулю)

    SRC_ID = 1, DST_ID = [ID модуля].

    Вместо маски передается CMD_ID (uint8_t).

    Если CMD_ID требует параметров, они идут в PAYLOAD.

    Пример: Команда 0x01 (Открыть багажник) -> MAGIC=0xBB, SRC=1, DST=3, SEQ=1, MASK_LEN=1, CMD_ID=0x01, CRC.
