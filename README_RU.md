# Fiona Brain 🧠🚗

**Центральный вычислительный и телеметрический хаб экосистемы «Душа Фионы».**

Fiona Brain — это микросервисная система на базе Linux, которая заменяет штатное головное устройство автомобиля. Она выступает в роли агрегатора данных, вычислительного центра виртуального бака и сетевого шлюза.

---

## 🌟 Что это такое?

Это «мозг» кастомной бортовой системы для Ford Focus 2001 (Фиона). Он работает на портативном компьютере под управлением Kubuntu, обменивается данными с ЭБУ по Bluetooth (ELM327) и с периферийными модулями (ESP32/ESP8266) по собственному UDP-протоколу.

- **Телеметрия OBD-II:** Чтение данных в реальном времени (Обороты, Скорость, MAF и др.) с 3-точечным сглаживанием.
- **Виртуальный бак:** Расчёт расхода топлива по MAF с учётом коррекций (STFT/LTFT). Прогрессивная калибровка («парадокс Зенона») и система пресетов заправок.
- **Сетевой протокол Fiona-Net:** Агрегация данных от модулей и широковещательный стрим (8-байтовая маска + CRC8).
- **Веб-дашборд:** Отзывчивый HTML/JS интерфейс (Порт 8000) для управления с телефона.
- **Интеграция с LIVI:** Трансляция данных в Android Auto через Socket.IO (Порт 4000).
- **Режим эмуляции:** Полноценное тестирование логики без подключения к машине (с защитой от записи на диск).
